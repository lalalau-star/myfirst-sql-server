# Point Of Sale SQL Server Database Project

## Overview
This project was developed as part of a SQL Server course by [Edutin Academy](https://edutin.com/curso-de-sql-server) to apply database design, data manipulation, querying, and automation concepts in a practical environment.

## Objectives
- Create and structure a relational database.
- Insert, update, and delete records.
- Retrieve and analyze data using SQL queries.
- Apply JOINs, subqueries, and aggregate functions.
- Implement views, stored procedures, and triggers.

## Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

## Project Structure
- `sql/`: SQL scripts organized by functionality.
- `docs/`: Database documentation and diagrams, if available.

## Key Concepts Applied
- Database and table creation
- Data manipulation (INSERT, UPDATE, DELETE)
- Data retrieval (SELECT, WHERE, ORDER BY)
- JOINs and subqueries
- Aggregate functions and GROUP BY
- Views
- Stored procedures to automate data insertion and stock counting
- Triggers

## How to Use
1. Install Microsoft SQL Server and SQL Server Management Studio.
2. Open the SQL scripts in the `sql/` directory.
3. Execute the scripts in the documented order.
4. Review the queries and their results in SQL Server Management Studio.

## Learning Outcomes
This project provided a practical understanding of relational databases, SQL querying, database automation, and SQL basics.
